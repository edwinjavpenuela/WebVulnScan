# Prerequisites

WebVulnScan requires:

- Python 3.10 or newer
- Nmap installed and available in PATH

Verify your environment:

```bash
python --version
nmap --version
```

Run a dry-run first:

```bash
python analisis_vulnerabilidades.py example.com --profile standard --dry-run
```

Optional local CLI install:

```bash
python -m pip install -e .
webvulnscan --help
```

Run an authorized scan:

```bash
python analisis_vulnerabilidades.py example.com --profile standard --confirm-authorized
```

Useful options:

- `--list-profiles`: show built-in scan profiles.
- `--profile quick|standard|web|deep|low-noise`: select scan behavior.
- `--ports 80,443,8080`: override profile ports.
- `--format text|json`: select report format.
- `--output reports/result.json`: save the report to disk.
- `--timeout 1800`: set the scan timeout in seconds.

Responsible use:

Only scan systems where you have explicit authorization. Some Nmap scan types may require elevated privileges depending on your operating system and selected profile.
